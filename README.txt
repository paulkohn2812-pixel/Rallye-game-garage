RALLY LEGENDS REBORN
===================
Eigenständiges kostenloses Arcade-Rallye-Spiel für Mobilbrowser.

Installation auf GitHub Pages:
1. index.html aus diesem Ordner herunterladen.
2. In deinem bestehenden Repository die bisherige index.html ersetzen.
3. GitHub Pages veröffentlicht die neue Version automatisch.
4. Safari neu laden (gegebenenfalls Cache umgehen).

Alternativ: Datei als reborn.html hochladen und unter /reborn.html öffnen.

Enthält: 5 Etappen, 4 Fahrzeuge, Upgrades, Trophäen, lokale Speicherung,
Touchsteuerung, prozedural gerenderte Strecken. Keine externen Bibliotheken.

Hinweis: Es handelt sich um eine eigenständige 2.5D-Arcade-Engine, nicht um
3D-Grafik auf dem Produktionsniveau eines kommerziellen Konsolenspiels.
